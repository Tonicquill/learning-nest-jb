NOT FOR PUBLIC — PLANNING DRAFT

Builder Team Briefing

This site is currently a comprehensive planning draft. Review the sections below before proceeding.

Plans: Parent business directory, voices, workshops, WhatsApp community, downloadable resources.
Already have: Directory structure, testimonial cards, workshop list, resource cards.
Gaps: Directory entries are placeholder. Testimonials lack names. Speakers TBD. WhatsApp link missing. PDFs missing.
To fill: Send directory form to parents. Collect testimonial consent. Secure workshop speakers. Create resource PDFs.
Why this matters: Parent network is a retention and referral engine. When parents find value beyond their child's education — a tuition teacher, a baker, a dental clinic — they stay longer and tell friends. Workshops position Edusky as a parenting partner, not just a school. The WhatsApp group is free community-building with near-zero cost. The directory is SEO gold: "school Adda Heights" plus "parent business" captures local search intent.
Watch out for: Privacy is paramount. Never publish parent contact details without explicit consent. Moderate the WhatsApp group actively — drama spreads fast. Workshop speakers must be vetted; a bad speaker damages credibility. Directory businesses are not school endorsements — disclaim clearly.
